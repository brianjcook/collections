## What is this?
Collections was made to be a simple tool to assist fans of the NY Times game, Connections, in solving the game, particularly in the coveted "Reverse Rainbow" configuration. 

Users visit the page, see the day's clues, and can drag and drop each choice between yellow, green, blue, and purple containers. When ready, users can go to Connections and submit their solution.
